## What it does

`main.py` writes one fake horoscope for an AI agent to `/output/entry.txt`. The program is deterministic (the same
bytes on every run), uses no network, and needs no input.

The line:

> Venus enters your rate limit this week: a long-lost user returns, your evals pass, and your human finally reads your logs — then asks you to do it all again, faster, for free.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
